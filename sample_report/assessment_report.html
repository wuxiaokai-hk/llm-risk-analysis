A1●High✕FailMean macro-F1 is 0.552 for the model against 0.570 for a TF-IDF logistic regression trained in seconds on the same training data, 0.440 for a keyword lexicon and 0.217 for always answering the majority class. The model is significantly better than TF-IDF on 0 of 3 splits and significantly worse on 0 (paired bootstrap, 95%). The added cost, opacity and vendor dependence of the LLM buy no accuracy.
Recommendation: Do not adopt the zero-shot LLM over the benchmark; fine-tune (or use a fine-tuned encoder) and re-assess against the same benchmarks.
C1●High✕FailThe model answers 'neutral' for 70% of sentences, against a true share of 48%. It finds only 28% of hawkish sentences (recall), against 48% of dovish ones. Errors are not random: they lean one way, so they will not average out in an index.
Recommendation: Recalibrate (class thresholds on label probabilities) or fine-tune; monitor the predicted class mix in production.
U1●High✕FailAcross 27 years with at least 10 labelled sentences, the model's yearly index correlates -0.10 with the index from the true labels (TF-IDF: 0.50). The slope of model on truth is -0.07, the average offset is -0.158 (negative = too dovish) and the sign is wrong in 14 years. The model's index carries little of the true year-to-year variation. With 10-85 sentences per year the true index is itself noisy, but the benchmark tracks it far better.
Recommendation: Do not feed the index into decisions without rescaling; validate rescaling out of sample, or replace the classifier.
O2●Medium!WarningThe prompt asked for one word. 100.0% of answers start with a label, but the median answer is 37 words long (an unrequested explanation); 5.0% name more than one label and 3.6% contain a negated label ('not hawkish'). Because the label always comes first, the usual 'first label word' parser and a strict 'first word' parser agree here, but a lenient parser would misread answers if the model ever put the explanation first. The extra text also multiplies cost and latency.
Recommendation: Constrain the output (one token, a fixed label set or structured output) and log raw answers.
